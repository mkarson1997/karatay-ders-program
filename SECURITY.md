# Security Policy

This repository is a client-side scheduling application and does not intentionally store credentials or sensitive user data.

If you discover a security issue affecting the deployed site, repository integrity, dependencies, exported content, or future users, please report it privately through the maintainer's GitHub profile before publishing exploit details.

A useful report includes reproduction steps, affected files, impact, and a suggested mitigation when available.

Do not commit secrets, credentials, private datasets, or production-only configuration to this repository.
